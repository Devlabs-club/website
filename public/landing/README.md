# Landing page AI images

Drop generated PNGs here with these exact filenames. Each section renders a soft
color-gradient fallback until the file exists (the `<img>` removes itself on error),
so the page looks finished and you can add images one at a time.

| File | Used in | Aspect | Vibe |
|------|---------|--------|------|
| `hero-meadow.png` | Hero banner | ~16:6 wide | Bright daylight green rolling hills with lavender/wildflowers, airy, optimistic |
| `testimonial-meadow.png` | Testimonial banner | ~16:7 wide | Dreamy pastel lavender/pink field, soft pink sky, ethereal |
| `workspace-meadow.png` | Product-card backdrop | ~4:3 | Close-up lavender field, soft focus, pastel green→purple |
| `cta-sunset.png` | Final CTA banner | ~16:6 wide | Cinematic golden-hour mountains + wildflower meadow, warm sunset |

Keep imagery soft, bright, and natural (the page is a light/editorial theme).
Leave the area where overlay cards/text sit relatively calm.
